# Jade Cursor — Luxury Spa Web Design Agency

> **Digital Sanctuaries for the World's Finest Spas, Wellness Retreats & Salons.**

Jade Cursor is a boutique digital agency crafting serene, high-performing websites and digital brands exclusively for luxury wellness havens. We blend tech precision with spa-like aesthetics.

---

## 🌿 Design Architecture & Principles

- **Pure HTML5 & Advanced CSS (Strictly Zero JavaScript)**:
  - Ultra-fast sub-second loading with zero framework overhead.
  - Pure CSS mobile navigation drawer via checkbox hack.
  - Native `<details>` & `<summary>` accordions for treatment menus and FAQs.
  - Pure CSS portfolio category filters.
  - Fixed CSS parallax scrolling on atmospheric sections.
  - Sticky mobile quick-booking bar (`<768px`).

- **Color System Tokens (`css/styles.css`)**:
  - **Deep Emerald**: `#071710` / `#0B2219` / `#1B4D3E`
  - **Sage Green**: `#F0F4F2` / `#D5E2DA` / `#8EA89D`
  - **Warm Cream**: `#FDFBF8` / `#FAF7F2` / `#F3ECE1`
  - **Slate Grey**: `#1C2722` / `#4B5B53`
  - **Champagne Gold**: `#C5A059` / `#EFE4CC`

- **Double-Bezel Nested UI (Doppelrand)**:
  - Concentric radii, tactile depth, and ambient elevation lifts.
  - Button-in-button trailing icon components with fluid hover kinetics.

## 🚀 Running Locally

You can open `index.html` directly in any web browser, or run the zero-dependency local server:

```bash
node server.js
```

Then visit [http://localhost:8080](http://localhost:8080).
